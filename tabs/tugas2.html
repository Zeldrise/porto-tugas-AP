Tugas 2 - Perhitungan Gaji Bersih (Algoritma Sekuensial)

Algoritma ini dirancang untuk menghitung total gaji bersih yang diterima seorang karyawan dalam satu bulan. Perhitungan dilakukan secara berurutan (sekuensial) dengan ketentuan sebagai berikut:

  • Gaji Pokok: Ditentukan melalui input user.
  • Pajak: Ditetapkan sebesar 10% dari Gaji Pokok.
  • Tunjangan Tetap: Ditetapkan sebesar Rp 500.000.
  • Gaji Bersih: Dihitung dengan rumus: Gaji Pokok - Pajak + Tunjangan
Catatan: Karena merupakan algoritma sekuensial, tidak ada percabangan (if/else) atau pengecekan kondisi tertentu. Instruksi dikerjakan secara berurutan dari atas ke bawah tanpa adanya kondisi percabangan. Jadi, untuk menentukan kategori gaji (seperti "Gaji Tinggi" atau "Gaji Standar"), kita harus menentukannya sendiri dengan melihat hasil perhitungan akhirnya.

Flowchart (Sekuensial)

Alur program berjalan lurus dari atas ke bawah tanpa simbol keputusan (belah ketupat):

  1. Mulai (Simbol Oval)
  2. Input gaji_pokok (Simbol Jajar Genjang)
  3. Proses pajak = gaji_pokok * 0.10 (Simbol Persegi Panjang)
  4. Proses gaji_bersih = gaji_pokok - pajak + 500.000 (Simbol Persegi Panjang)
  5. Output gaji_bersih (Simbol Jajar Genjang)
  6. Selesai (Simbol Oval)

Kalimat Deskriptif dan Pseudocode

Algoritma_Hitung_Gaji_Bersih:

  1. Masukkan besaran Gaji Pokok.
  2. Hitung nilai Pajak dengan mengalikan Gaji Pokok dengan 0.10.
  3. Hitung Gaji Bersih dengan menjumlahkan bobot masing-masing nilai (Gaji Pokok - Pajak + Tunjangan).
  4. Tampilkan hasil Gaji Bersih ke layar.

Pseudocode:

PROGRAM HitungGajiBersih
DEKLARASI
    gaji_pokok, pajak, gaji_bersih : float
ALGORITMA
    read (gaji_pokok)
    pajak <- gaji_pokok * 0.10
    gaji_bersih <- gaji_pokok - pajak + 500000
    write (gaji_bersih)
End

Source Code JavaScript

Berikut adalah kode asli pemrograman JavaScript berbasis console terminal yang digunakan untuk mengimplementasikan algoritma di atas menggunakan modul readline:

const readline = require("readline").createInterface({
    input: process.stdin,
    output: process.stdout
});

readline.question("Masukkan Gaji Pokok: ", (input_gaji) => {
    let gaji_pokok = parseFloat(input_gaji);
    let pajak = gaji_pokok * 0.1;
    let tunjangan = 500000;
    let gaji_bersih = gaji_pokok - pajak + tunjangan;

    console.log(`Pajak (10%) : ${pajak}`);
    console.log(`Tunjangan   : ${tunjangan}`);
    console.log(`Gaji Bersih : ${gaji_bersih}`);

    readline.close();
});
